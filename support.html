Support

Nimbus is a download manager for Mac. It downloads files over HTTP and HTTPS from links you provide, and it keeps those files on your computer.

Questions, feedback, and feature requests: amroqazzaz@gmail.com.

System requirements

Nimbus requires macOS 13 or later.

How to download a file

  • Open Nimbus and paste a direct HTTP or HTTPS link, or drop a list of links onto the window.
  • Or, in Safari, use the Nimbus extension, or share a link to Nimbus from the Share sheet in Safari or other apps.
  • Choose a destination: your Downloads folder, or a folder you pick.
  • Start the transfer. You can pause and resume, including after you quit Nimbus or restart your Mac.

When a server supports HTTP Range requests, Nimbus can split a file across several connections to finish sooner. If the server does not support ranges, Nimbus falls back to a normal single-connection download.

Queues, schedule, and daily quota

  • Queues let you line up several files and control how many run at once.
  • The scheduler can start or stop queues at times you set.
  • An optional daily quota caps how much is downloaded in a day.

Progress is also available from the menu bar, so you do not have to keep the main window open.

Nimbus Pro

Nimbus Pro is an optional one-time in-app purchase. There is no subscription. Buy or restore it from the unlock sheet in the app. Purchases are handled by Apple through the App Store. If you reinstall Nimbus or move to another Mac signed in with the same Apple Account, use Restore Purchases.

What this App Store edition does not do

Nimbus downloads direct HTTP and HTTPS files only. It does not download videos from YouTube or other media sites, it does not grab or copy entire websites, and it does not download torrents or magnet links. It is not a web browser.

If something does not behave as expected

  • A file downloads with one connection when the server does not support HTTP Range requests. Several connections are used only when the server allows them.
  • Pause and resume, including after you quit Nimbus or restart your Mac, applies to a transfer you already started.
  • If Nimbus cannot save outside your Downloads folder, choose the folder again. Access to other folders is granted only when you select them.
  • To use the Safari extension, turn it on in Safari Settings, under Extensions. It sends a link you chose to Nimbus on the same Mac.
  • If Nimbus Pro looks locked after you reinstall Nimbus or use another Mac, open the unlock sheet and use Restore Purchases with the same Apple Account.

Privacy

Downloads go directly from the servers you specify to your Mac. Nimbus does not create an account and does not collect personal data. For the full policy, see the Privacy Policy.
